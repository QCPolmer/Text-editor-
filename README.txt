OK, the idea is to get a bunch of vim 
features (from my custom vimrc) as 
a single-page online website.

Also has MSX style in text commands:
lines started with 
';' will run the line as js,
lines betweeen
//START//
and 
//END// 
will run as js code once 'enter'
is pressed on the //END// line. 

(jk-> enters normal mode, 
df in normal mode for menu)

AI (gemini) helped with some of the low-
level stuff.
Grok also did some troubleshooting.
